# 上辈子是什么动物

动物塑 · 前世动物人格小测验（仅供娱乐）

线上地址：<https://zengpenghui420-glitch.github.io/animal-past/>

用手机浏览器打开。首页输入小红书订单号后开始；12 道日常小题，结果是 12 种前世动物里气质最接近的一只（含雪狐，稀有结果为乌鸦）。结果可左右滑动，分享图为 9:16。
