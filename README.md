# 上辈子是什么动物

动物塑 · 前世动物人格小测验（仅供娱乐）

线上地址：<https://zengpenghui420-glitch.github.io/animal-past/>

用手机浏览器打开。首页输入 `AP` 开头的 6 位验证码后开始；12 道日常小题，结果是 12 种前世动物里气质最接近的一只（含雪狐，稀有结果为乌鸦）。结果可左右滑动，分享图为 9:16。

## 验证码

| 项 | 值 |
|---|---|
| 前缀 | `AP` + 4 位 |
| 集合 | MantleDB `catquiz-zph420-codes` / `ap/` |
| 次数 | 每个码 3 次 |
| 重新测试 | 再次核销，扣 1 次 |
| 查看上次结果 | 只读本地记录，不扣次 |

其他测验的验证码不能用在这里。卖家说明见 [CODES.md](CODES.md)。
