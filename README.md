# 上辈子是什么动物

动物塑 · 前世动物人格小测验（仅供娱乐）

线上地址：<https://zengpenghui420-glitch.github.io/animal-past/>

用手机浏览器打开。首页输入小红书订单号后开始；12 道日常小题，结果是 12 种前世动物里气质最接近的一只（含雪狐，稀有结果为乌鸦）。结果可左右滑动，分享图为 9:16。

## 订单号

只接受 `P` + 18 位。重复数字块、逐位加一或减一、以及 19 位号码都会提示「订单号格式不对」，不会开始测验。格式通过后立即开始。页面不为订单号请求 `*.vercel.app`，也不读写 Mantle 的 `orders/`。

| 项 | 值 |
|---|---|
| 入口 | 到小红书「我的订单」复制订单号 |
| 通过 | 解锁并开始测验 |
| 第一次 | 「验证成功，还可以测 2 次」 |
| 再测一次 | 先显示「还可以测 1 次」，再显示「这是最后一次」 |
| 刷新、继续这一次、查看上次结果、刷新结果 | 不改变上面的显示 |
| 显示过 3 次之后 | 同一订单号仍可进入，提示「验证成功」 |

已发出的旧码仍先走 vault `POST /redeem`（quiz `animal`）。vault 没有这枚码时，才核销本页原来的 Mantle `ap/`，按真实剩余次数计算。vault 明确用尽则不再落到 Mantle。

## 本地预览

```bash
python3 -m http.server 8080
```

打开 <http://127.0.0.1:8080/> 。页面是单文件 `index.html`，GitHub Pages 从 `main` 分支根目录发布。
